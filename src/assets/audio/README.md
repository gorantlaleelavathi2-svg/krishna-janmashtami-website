# Audio

Drop a royalty-free / licensed flute loop here as:

    flute-loop.mp3

`MusicPlayer.jsx` looks for this file first. If it isn't present, the
"Play Krishna's Flute" button automatically falls back to a soft
synthesized flute-like tone generated in the browser via the Web Audio
API — so the feature works even with no audio file bundled.

Do not add copyrighted commercial recordings without a license.
