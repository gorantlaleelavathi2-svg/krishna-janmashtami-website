# Images

`Gallery.jsx` currently renders themed gradient tiles as placeholders so
the site needs no external images to run.

To use real photos: add your files here (e.g. `krishna-1.jpg`), then in
`Gallery.jsx` replace an item's `gradient`/`icon` rendering with an
`<img src="/src/assets/images/krishna-1.jpg" alt="..." />`.

Only use images you have the rights to use.
